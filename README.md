# zeta-be.github.io

Portada de la organización ZetaBé en GitHub Pages: https://zetabe.agency/

Este repo es el que lleva el dominio propio de la organización (Settings → Pages → Custom domain = `zetabe.agency`).
Con él, cada repo de Zeta-Be con Pages queda publicado en `zetabe.agency/<repo>` (OASIS: https://zetabe.agency/OASIS/).

No lleva datos ni claves: solo la portada.
